## 1. 启动信息调整（内置包信息隐藏 / 版本徽标 / 本机 IP）

**诉求**：
1. 启动时不要在内置日志窗口显示内置 APK 信息（等于告诉别人 App 里有资源）。
2. 界面顶部右侧加版本信息，每次打包都要更新版本。
3. 启动时把手机本机 IP 输出到日志窗口。

**落地**

| 改动 | 文件 | 说明 |
|---|---|---|
| 内置包信息不再进日志 | `MainActivity.java` | `logBuiltinInfo()` → `prepareBuiltin()`，只清理历史 `cache/builtin.apk`，不再调用 `log()`；包名/应用名仍由 `readBuiltinMeta()` 读取，仅用于安装弹窗与应用名展示 |

| 启动日志加本机 IP | `MainActivity.java` | 新增 `localIp()`：遍历 `NetworkInterface`，优先 `wlan*` 的 IPv4，跳过回环/链路本地；失败给友好提示 |
| 版本徽标 | `activity_main.xml` + `bg_ver_badge.xml` | 标题下方单独一行右对齐，10sp 半透明白底圆角，显示 `v1.0.2 · 1118-0901` |
| 版本号 + 构建标记 | `app/build.gradle` | `versionCode 3` / `versionName "1.0.2"`；`resValue "string","build_stamp"` 生成 `MMdd-HHmm`，每次打包都不同 |
| AGP 9 开关 | `app/build.gradle` | 必须加 `buildFeatures { resValues true }`，否则报 `defaultConfig contains custom resource values, but the feature is disabled` |

## 3. 「安装软件」弹窗改版（v1.0.4 ~ v1.0.6）

**诉求**
1. 点「安装软件」先弹窗，默认显示随包携带的软件：应用名称、包名、版本信息。
2. 打包时 `apk\` 目录没放 APK，弹窗就**不显示任何安装包信息**（空态）。
3. 弹窗加一个按钮，让用户从手机本地目录自选 APK 安装。
4. 弹窗里**不出现「内置」这类关键词**。
5. 选完自选包**不能直接装**，必须再点右下角「安装应用」；按钮文字固定为「安装应用」。
6. 既没有随包资源、也没选文件时，点「安装应用」提示「请选择APK安装包文件」。

**落地**
- `app\build.gradle` 的 `syncBuiltinApk`：`apk\` 为空不再抛异常，改为删旧 `hpt_payload.dat`、写空 `payload.idx`（`size=0/encSize=0`），日志「apk 目录下没有安装包 → 本次打包不内置安装包」；同时用 aapt 解析 `versionName`/`versionCode` 写入 `payload.idx`。
- `MainActivity`：`BuiltinMeta` 增加 `versionName`/`versionCode`；`hasBuiltin(meta)` 判 `size>0`；`versionText(meta)` 拼 `P8-Hi V5.0.4（versionCode 504）`。
- 弹窗改为**状态式**（`installDialog` + `installInfoView` + `installSession` + `pickedUri/pickedName/pickedSize`）：正文「目标设备 / 待安装应用（应用名称·包名·版本·大小）/ 已选择安装包：…」，按钮固定「从手机选择 APK」「取消」「安装应用」。
- 「安装应用」点击由 `installDialog.getButton(...).setOnClickListener` 自己接管（不自动 dismiss）：有自选包 → 走 `installFromUri`；无自选包但有随包资源 → 走 `doInstall`；两者都没有 → Toast「请选择APK安装包文件」，弹窗不关。
- 自选包链路：`ACTION_GET_CONTENT` + `application/vnd.android.package-archive` → `onActivityResult` 只记录 `uri/文件名/大小` 并刷新弹窗正文 + Toast「请点「安装应用」开始安装」，不再自动安装。
- `AdbDevice.installApk` 支持「大小未知」（`size<=0`）：进度按 1MB 步长汇报，校验改为 `actual>0`，日志「安装包大小未知，按实际收到字节校验：…」。
- 把默认 label `内置应用` 改成 `未命名应用`，确保弹窗任何情况下都不出现「内置」字样。

**踩坑**
- `AlertDialog.setView(...)` 复用同一个 TextView：旧弹窗关闭后视图仍挂在旧 Dialog 上，第二次 `show()` 抛 `IllegalStateException: The specified child already has a parent`，直接崩溃退出到桌面（`logcat -b crash` 已抓到）。修法：每次 `showInstallDialog()` 都 `new TextView(this)`。
- 重装 App 会把文件选择器等前台界面一起干掉，重装后必须 `am force-stop` + `am start` 再走流程。
- 该设备 adbd 在连接约 20 秒后会主动断一次（`SocketException: Software caused connection abort`），所以流程改成「选包 → 取消 → 重新连接 → 安装软件 → 安装应用」，已选 APK 会保留（v1.0.8/v1.0.9）。

**验证**（真机 Redmi Note 13 Pro + HPT-P8 `192.168.0.49:5555`）
- 空态构建（临时把 `apk\` 里的包移走）：弹窗只有「本次未随应用打包安装包文件，请点「从手机选择 APK」选择安装包。」+「已选择安装包：无」+ 三按钮（`doc\shot_i1_empty_dialog_s.jpg`）。
