## 1. 本轮（第 1 轮）：基础 APP 从零搭建

**用户诉求**：顶部标题、投屏画布、设备地址+端口输入、连接按钮、设备信息表格（设备名/连接信息/投屏/断开/重启）、安装软件/卸载软件（内置打包一个 APK）、日志框；手机无 root；打包后直接装到手机。

**落地**：
- 纯 Java 手写 ADB 协议：`AdbConnection`（CNXN/AUTH/OPEN/OKAY/WRTE/CLSE）、`AdbCrypto`（RSA 2048+SHA1、Android 私有 `RSAPublicKey` 结构）、`AdbDevice`（shell/exec/push/install/列包/卸载/重启）、`AdbStream`。
- 内置包加密：`syncBuiltinApk` 构建任务把 `apk\` 下最新 APK 用 4MB 分块 AES-256-GCM 加密成 assets 资源；`BuiltinApkStream` 边解密边上传，装完删设备临时文件，明文不落盘。

**踩坑**：CNXN 报文头 `a0` 必须是版本 `0x01000001`、`a1` 才是 `maxData=262144`；`a0`=local-id、`a1`=remote-id；收到 CLSE 只标记不回包；报文头 magic 必须 `cmd ^ 0xFFFFFFFF`。

## 3. 第 3 轮：scrcpy-server + MediaCodec 真视频流 + 全屏鼠控

**诉求**：要真流畅就换 scrcpy-server + MediaCodec，全屏支持鼠控，退出全屏只显示视频流不支持鼠控。

**落地**：
- 新增 `ScrcpyServer`（每次强推 jar + `wc -c` 校验 + `killOld()` + `shell:` 拉起 + `cleanup=false`）、`ScrcpyControl`（32B 大端 touch 报文）、`ScrcpyMirror`（MediaCodec + 帧率统计 + 触控）、`PreviewView` 改 `FrameLayout` 直出 `TextureView`。
- 实测：`1024x576`、10.8~13.6 FPS、全屏点按可穿透到目标机（弹「参数设置」）、旋转切横向触控同步、退出全屏视频继续且触控关闭。

**踩坑（已固化结论）**：服务端选项名是 `video_bit_rate`；`app_process` 找不到类会 SIGABRT（jar 被 cleanup 删掉）；视频头 76 字节顺序（哑字节→设备名→fourcc→宽→高），且必须先连控制通道；pts 高两位是标志位要 mask + 单调保护；`releaseOutputBuffer(idx,false)` 不渲染；`ImageReader` 路径间歇 SIGABRT 故弃用。

**随后修的两个真 bug**：① 全屏黑屏 = `onSurfaceTextureDestroyed` 返回 true 导致解码线程 `Invalid to call at Released state` 退出 → 改返回 false + 解码循环 try/catch 不退出 + `rebindVideoSurface()`；② 全屏一点就崩 = UI 线程写 socket `NetworkOnMainThreadException` → 触控改单线程 `touchExec`；③ 触控坐标算成 (-1,-1) = 控制通道先建立时 w/h 还是 0 → 读完视频头 `setVideoSize(w,h)`。

## 9. 第 7 轮（同日追加）：投屏不成功 → OPEN 少结尾 NUL

**现象**：点「投屏」后卡在「视频端口连接失败（第 30 次）…设备拒绝打开该服务」，35s 后自动重启服务端仍不通；日志里设备端 `Device: rockchip HPT-R3568` 已打印，说明服务端起来了。

**定位**：
1. 设备端 `ps` / `/proc/net/unix` → `@scrcpy` listening，服务端正常。
2. PC 侧 `adb forward tcp:27183 localabstract:scrcpy` + python 连接 → 立刻收到视频头哑字节 `0x00`，adbd 通道正常。
3. `doc\adb_open_probe.py` 对照实验：服务名带 `\0`（21 字节）→ `OKAY`；不带 NUL（20 字节）→ `CLSE`。我们日志里 OPEN 长度正是 20 → 根因确认。

**修复**：`AdbConnection.openStream()` 统一 `service + "\0"`（shell/exec/sync/localabstract 全走这条路径）。

**验证**：视频端口第 2 次尝试即通（23ms），`H264 1024x576`、10.5~10.8 FPS、控制通道 3ms 就绪；全屏进入/旋转/退出全屏视频均继续；「安装软件」回归成功（62.0 MB，临时文件已删）。截图 `doc\shot_d1_mirror~d4_exitfull.png`。

**新增工具**：`doc\adb_open_probe.py`（纯 Python 最小 ADB 客户端，只发 CNXN + OPEN，可对比 NUL 变体），用法 `python doc\adb_open_probe.py 192.168.0.226 5555 localabstract:scrcpy`。
